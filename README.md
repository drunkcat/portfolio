# Portfolio — Data Science & AI

Jestem deweloperem multimedialnym, który rozwija się w obszarze Data Science, Machine Learning i AI. Łączę doświadczenie programistyczne z ciekawością analizy danych i praktycznego wykorzystania modeli.

W portfolio prezentuję projekty obejmujące analizę i wizualizację danych, modelowanie oraz wyszukiwanie informacji w tekstach. To zapis mojej nauki i eksperymentów — od poznawania danych po tworzenie rozwiązań, które można przetestować w praktyce.
