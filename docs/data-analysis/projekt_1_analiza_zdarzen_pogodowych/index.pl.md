# Przegląd zdarzeń pogodowych

Podstawowa analiza próbki rekordów zdarzeń pogodowych NOAA. Notebook przedstawia typy zdarzeń, liczbę zgłoszeń według miesięcy i stanów, raportowane szkody w mieniu, rannych oraz ofiary śmiertelne.

## Pliki projektu

- [Otwórz lub pobierz notebook Jupyter](analiza_zdarzen_pogodowych.ipynb)
- [Próbka danych (CSV)](storm_data_sample.csv)
- [Opis formatu eksportu NOAA (PDF)](storm-data-export-format.pdf)

Dostarczony plik CSV jest próbką obejmującą około jednej dziesiątej pełnego zbioru. Wyników z tej próbki nie należy traktować jako kompletnego obrazu zdarzeń pogodowych.
