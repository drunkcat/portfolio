# Weather Events Analysis

An introductory analysis of a sample of NOAA storm event records. The notebook explores event types, monthly and state-level counts, reported property damage, injuries, and fatalities.

## Project files

- [Open or download the Jupyter notebook](analiza_zdarzen_pogodowych.ipynb)
- [Sample data (CSV)](storm_data_sample.csv)
- [NOAA export format reference (PDF)](storm-data-export-format.pdf)

The supplied CSV is a sample representing approximately one tenth of the full dataset. Results from this sample should not be treated as a complete picture of storm events.
