# About

I'm a multimedia developer with experience creating games, interactive applications and e-learning projects. I have combined programming with the design of graphics, animation and interactions, which helps me look at applications from both a technical and a user perspective.

I'm currently developing my skills in Data Science, Machine Learning and AI. In my projects, I use Python — pandas, NumPy, Matplotlib and Seaborn — for data analysis and visualisation, as well as scikit-learn and PyCaret to work with models. I'm also exploring text-processing methods such as TF-IDF and using Streamlit to build simple applications that present results.

My portfolio shows different stages of this work: analysing weather events using NOAA data, modelling and segmentation in an insurance project, and searching text-based materials for information. I'm interested in practical approaches and solutions that can be run, tested and put to use.
