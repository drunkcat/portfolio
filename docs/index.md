# Data Science & AI

## Building by exploring

My projects often begin with simple sparks of curiosity: “what if…?”, “can this be done…?”, “how will the result change if I approach it differently?”. In Data Science, Machine Learning and AI, I give myself room to experiment — testing ideas, refining them, sometimes breaking them and putting them back together, until an initial curiosity leads to a solution that really works.

This portfolio is a collection of these processes: a place where intuition meets analysis, and ideas travel from a rough sketch to a working project.

### Data Analysis — Weather Events Overview

How often do different types of weather events occur, and what damage do they cause? In this notebook, I analyse a NOAA data sample, comparing event counts, injuries, fatalities and reported property damage.

### Machine Learning — Insurance Premium Analysis

This app estimates an insurance premium and assigns a profile to a group of similar customers. Users can enter details manually or describe them in text, while pre-trained models generate the predictions.
